# Security Policy

VulnLens is early-stage heuristic software. It can produce false positives and miss vulnerabilities; a clean result is not proof of security.

Please use GitHub private vulnerability reporting if enabled. Do not post live credentials, private code, or sensitive details in public issues. Reproduce findings with harmless fixtures when possible.

Only scan repositories and systems you own or have explicit permission to assess. The scanner reads local files and does not intentionally transmit scanned content.
